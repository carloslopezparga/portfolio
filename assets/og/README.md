# Social card fonts

TrueType files used only on the server, by `app/[lang]/opengraph-image.tsx`
(the card renderer cannot read the WOFF2 files `next/font` serves to the page):
the site's display face, Plus Jakarta Sans (600, 700), and its body face,
Inter (400, 500). Both from Google Fonts, under the SIL Open Font License 1.1
(https://openfontlicense.org).
