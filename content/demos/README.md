# Recorded demos

`job-hunt-copilot.txt` — a real run of the CLI, replayed as an animated terminal. Until this file exists, the project shows no demo.

Format (plain text):

```
$ job-hunt-copilot scan        ← lines starting with "$ " are typed character by character
Fetching boards…               ← every other line is printed as output
# @pause 1.5                   ← waits 1.5 s, never shown
```

ANSI colour codes from the real terminal are kept (green, cyan, bold, dim…).
Before committing, remove anything private from the run (emails, phone numbers, tokens, URLs with personal data).
